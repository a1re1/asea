# Archipelago assets (CC0)

Original low-poly toon sailing-adventure meshes. Dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No external copyrighted art.

Generated by `tools/create_assets.py` (Blender 5.2.1 background). Runtime files live in `assets/models/*.glb`. Source `assets/source/archipelago_assets.blend` is excluded from Godot via `assets/source/.gdignore`.

## Regeneration

From the repo root:

```
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python tools/create_assets.py
```

Deterministic: same Blender version and script produce the same meshes. No network.

## Conventions

- Godot / glTF: **Y up**, units = meters.
- Boat bow toward **-Z**. Origin at **waterline** (keel drafts below Y=0).
- Props: origin at **ground** (min Y ≈ 0) except buoy (waterline, min Y ≈ −0.30).
- Materials: opaque Principled BSDF, warm saturated palette, no textures / no external buffers.
- Static props export **one mesh per material**. Boat keeps named `Boat_Sail`, child `Boat_Sail_Emblem`, and `Boat_Flag` unmerged.
- **All seven exports are static** (no baked glTF animation clips). Godot animates the boat's bob, sail and flag at runtime in `scripts/boat.gd`.
